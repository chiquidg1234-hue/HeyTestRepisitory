# Entorno

Verificador de tipos disponible. Las definiciones de la API de Roblox están
en `./globalTypes.d.luau`, dentro de este proyecto.

```bash
luau-lsp analyze --platform=roblox --defs=./globalTypes.d.luau <ficheros.luau>
```

Sale con código 0 si no hay errores. **No des la tarea por terminada hasta que salga limpio.**
